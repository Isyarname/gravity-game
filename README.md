An interactive 2D gravitational N-body simulation developed in Python using Pygame. Features include intuitive mouse-based body creation with velocity vector control, unique color coding for each mass, real-time trajectory tracing, camera zooming, and realistic inelastic collisions where bodies merge upon impact.
